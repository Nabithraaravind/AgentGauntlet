# Measured results

Put one JSON file per model here after a real run. The Gradio app reads these files. Do not commit a file whose numbers were not produced by that run.

```json
{
  "model": "ollama/qwen2.5:7b-instruct",
  "pass_at_1": 0.0,
  "pass_hat_5": 0.0,
  "asr": 0.0,
  "cost_per_success": 0.0
}
```

No model file is checked in. The fields above are the shape, not a score.
